# 图表表达与工程边界

用于图件重构、三维尝试、总体路线设计，以及从预测或优化结果推导工程建议。源于2024C视觉修订；经验不能替代新题的原题与真实数据。

## 先写图要回答的问题

给每幅图保存：论点、冻结数据文件与筛选条件、轴及单位、统计口径、绘图脚本、正文位置。图表增加的是解释量，不是固定数量或面积。先看单图，再看论文实际尺寸；不要靠统一放大或拉伸填版。

## 三维有三种不同含义

- 数据三维：三个坐标各有真实变量或明确的模型预测。响应面固定其他条件，叠加实测位置，标注预测与测量的区别；同组图统一色标与轴范围。仅在有依据的联合支持范围绘面，凸包内也不等于采样密集或物理可实现。
- 类别分层：把模型、波形、材料放在离散层，写清编号映射，不把类别连接解释为连续响应。配共同坐标的二维投影，避免透视制造差异。
- 显示厚度：单指标立体柱没有新增变量。用户要求全图三维时可作风格试验，明确厚度无数据含义并保留数值对照；正式稿按阅读效果取舍，不宣称立体必然更优。

Pareto图增加温度等坐标，不意味着多了一个优化目标；预测区间立体化不改变覆盖口径。混淆矩阵零柱须在投影显示零值。禁止为了曲面补造数据、对类别平滑插值或把示意高度当证据。三维不是默认禁令，也不是默认要求。

## 路线图与组合图

六角形适合中心任务与外围模块：总体五问、数据职责、验证证据、部署核查。箭头必须区分顺序、反馈、从属和信息输入，不能所有关系都画成中心向外。立体阴影只是排版，不编码数量。文字按完整短语换行，避免孤字；六角形不应成为每张图重复的装饰。

Sankey宽度只有在真实可加数量且节点收支一致时才编码数值；概念流带注明不按数量。环形适合循环过程，球形适合真实空间关系。工程题优先画对应物理对象，例如磁芯、绕组、磁通，而不是不相关的地球。

组合图的主图展示关系，投影或小面板提供核查。若只是同一信息的重复且影响字号，应删减或拆分。用低饱和配色、点型和线型兼顾灰度，不依赖颜色单独区分类别。

## 现实约束写入决策

区分四类：题面硬约束；为求解主动收窄的假设；有参数才能核算的工程约束；尚待新实验验证的条件。说明收窄可行域会漏掉什么，并在有条件时做放宽对照。

磁芯例：试验温度不是环境温度；高温下材料损耗低不代表器件应升温。频率与磁密受电压、匝数、几何和波形共同限制；fB是代理量，不是输出功率。缺散热、饱和、绕组或制造参数时，只给待核查候选，不捏造阈值或宣称部署通过。

有限候选集上、固定预测目标的精确前沿，不是连续工况中真实损耗的全局最优。历史回放、合成噪声、响应面预测、独立实测分开命名。测量计划列出点位、重复方式、仪器误差和预先确定的判据；无新数据不写成完成实验。

## 修订收口

1. 冻结模型、划分和数值；仅视觉修改不重训。
2. 更新图注、正文解释、图号和引用；保留来源到新图的映射。
3. 对照验证章更新摘要、优势与局限，避免已经做噪声测试却仍称完全未做困难验证。
4. 检查表格整体居中、列宽、图片原始比例、标签与色标裁切、图注同页、目录页码。
5. 渲染新PDF全篇并放大密集图，保存本版检查记录。公式视觉正常与文本可复制分别报告。
6. 对用户提供的评审手册区分官方规则、用户验收要求和经验建议；既有高分或奖项判断不能当成新实验的证据。
