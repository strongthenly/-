# 环境与复现

流程本身只需可读取本地文件的Codex和Python 3.10+。doctor使用标准库只读探测，不安装依赖、不读取密钥、不发送网络请求。

|能力|何时需要|常见实现|
|---|---|---|
|数值与数据|真实求解|NumPy、pandas、SciPy|
|统计/预测|题目有此需求|scikit-learn、statsmodels；XGBoost按需|
|精确整数优化|需要小例精确证据|OR-Tools/CP-SAT或适合问题的求解器|
|科学图件|论文图表|Matplotlib，输出PDF/SVG/PNG|
|中文原生PDF|完整论文交付|TeX Live或MiKTeX中的XeLaTeX、ctex、Fandol|
|PDF渲染/检查|确认版式|PyMuPDF或Poppler；结合人工/视觉模型逐页查看|
|官方Excel|题目要求表格答案|openpyxl或当前环境可用的表格工具|

先运行doctor，再复用已有环境。新独立项目可自行创建虚拟环境；仅缺失时安装所需库，不要求安装全部机器学习/优化包。安装结束用`python -m pip freeze`保存已实际使用环境的锁定记录。库版本改变后重算关键指标；本包没有把某台电脑的未来版本号钉死为通用依赖。

Windows、Linux和macOS可使用同一Python脚本。TeX发行版需单独安装；在正式练习前用技能assets/smoke.tex试编译一次中文、分式、求和和表格，渲染并检查。Fandol来自TeX环境，不捆绑商业字体。若只能文本处理而无法执行/渲染，明确降低交付范围，不能宣称PDF已检查。

```bash
xelatex -interaction=nonstopmode -halt-on-error smoke.tex
```

建议在新项目latex目录复制模板后执行；模板仅用于环境冒烟检查，不是40页论文填空题。输出中的1/2只是测试公式，不是实验结果。

项目移植需同时搬运合法数据、代码、结果与环境记录；目录连接不会自动成为便携数据。不要依赖Codex私有Node运行库、artifact操作标记器或本机浏览器。目标环境已有相关插件时可使用，缺少时选择等价库。本流程不负责安装GPT-6，也不绕过账户权限。
